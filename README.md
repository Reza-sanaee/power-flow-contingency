# Seven-Bus Power-Flow and Contingency Analysis in PowerWorld

A PowerWorld study builds a seven-bus transmission network and evaluates load flow, reactive compensation, transformer taps/parallel paths, line outages, and generator relocation. The report distinguishes steady-state limit checks from dynamic stability and optimization claims.

## Technical highlights

- Co-modeled a seven-bus network in PowerWorld and evaluated voltage/reactive-power behavior under topology and operating-point changes.
- Compared power-flow methods and studied capacitor removal, transformer taps, parallel branches, and selected contingencies.
